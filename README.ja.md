# Create Train Next

[English](README.md)

Createの列車用レールを、45度や90度の刻みにとらわれず、好きな角度の曲線で敷けるアドオンです。曲線を引く杖に加えて、日本式の信号機（2灯式から6灯式）や速度制限標識など、線路脇の設備も追加します。

| 項目 | 対応 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.248以上 |
| Create | 6.0.x（動作確認は6.0.10） |

## 特長

- 始点と終点を右クリックするだけで、好きな角度の曲線を敷けます。敷く前に予告線（ゴースト）が出て、緑なら敷設でき、赤なら敷けません。15度の倍数に近い角度はその角度に引き寄せられるので、45度や90度が正確に出ます。
- 敷いた曲線は、Createの列車がそのまま走ります。信号機もCreateの信号の仕組みに載せてあります。
- 高さの違う2点は、一定の勾配でつながります。勾配はアンカーが覚えているので、登りは階段状になりません。ダッシュキーを押しながらスクロールして勾配を決めると、杖はルート全体をその勾配で敷きます。
- 方位、長さ、勾配を決めて、真っすぐな線路を引ける測量標があります。
- 曲線のレールと同じ高さに見えない床を並べるので、曲線の上を歩けます。
- 日本式の2灯式、3灯式、4灯式、5灯式、6灯式の信号機と、中継信号機、速度制限標識、信号機を支える信号柱を追加します。
- Createのものも、このModのものも、信号機や駅を、接続点を足さずに曲線の上へ直接置けます。
- 線路の状態を調べて直すコマンドがあります。

## 導入

必要なものは、Minecraft 1.21.1、NeoForge、Create本体です。PonderとFlywheelはCreateに同梱されているので、別に入れる必要はありません。マルチプレイでは、サーバーとクライアントの両方に同じ版を入れてください。

配布ページはまだありません。ソースからjarをビルドして、`mods`フォルダに入れます。ビルドの手順は「開発」の節にあります。

## 使い方

### 曲線を敷く

曲線は曲線レール設置杖（以下、杖）で敷きます。曲線の端に必要なアンカーは杖が自動で置くので、先に置く必要はありません。

1. 杖を持ち、曲線を始める線路（Createの線路、またはアンカー）を右クリックします。
2. 曲線を敷きたい場所に視線を向けます。始点から視線の先まで、ゴーストが表示されます。
3. ゴーストが緑のときに右クリックすると、ゴーストのとおりに敷設されます。

敷設したあとも選択は終点に残るので、続けて右クリックすると、1本ずつルートが先へ伸びます。

片方の端の向きがすでに決まっているとき（Createの線路や、曲線がつながったアンカーなど）は、もう一方の端の向きを、全体が円弧になるように自動で決めます。角度の入力は要りません。実際の鉄道に近い曲線になります。

ホットバーの上のメッセージに、曲線の長さ、曲がる角度、到着時の方位が出ます。方位の数え方はMinecraftと同じで、南が0度、時計回りに増える点に注意してください。北東などの方角も併記されます。

曲線が登りか下りのときは、別の行に、勾配（‰。水平1000ブロックあたり何ブロック上がるか）、1ブロック上がるのに必要な水平距離、曲線全体の水平距離、上がる高さが出ます。この勾配は曲線全体の平均です。ただし、急すぎるかどうかの判定は最も急な所で行う決まりです。登りへ滑らかに入る曲線は、平均より大きい値で断られることもあります。

| 操作 | 動作 |
|---|---|
| 線路かアンカーを右クリック | その場所から曲線を始めます。アンカーは、片側が空いていれば始点にできます。 |
| 行き先のブロックを右クリック（選択中） | ゴーストのとおりに曲線を敷き、選択を終点に移します。 |
| 別のルートの端を右クリック（選択中） | 2本のルートをつなぎます。 |
| スニークしながらスクロール（選択中） | 先端の向きを手で回します。1目盛り2.5度、ダッシュキーを押している間は15度で、最大±85度です。 |
| ダッシュキーを押し、スニークせずにスクロール（選択中） | 敷設する勾配を決めます。1目盛り5‰です。詳しくは下の「勾配をつけて敷く」を参照してください。 |
| 空中を右クリック（手で回したあと） | 自動の円弧に戻します。 |
| スニークしながら空中を右クリック（選択中、勾配モード以外） | 選択を解除します。 |
| スニークしながら空中を右クリック（勾配モード中） | 勾配と水平距離を入力する画面を開きます。 |
| スニークしながらアンカーを右クリック | そのアンカーにつながった曲線を外します。 |
| スニークしながらそれ以外のブロックを右クリック（選択中） | 選択を解除します。勾配モード中も使えます。 |
| スニークしながら曲線の近くを右クリック（選択なし） | 曲線の途中に接続点（アンカー）を足します。 |

敷けないときはゴーストが赤くなり、理由がメッセージに出ます。

| メッセージ | 意味 |
|---|---|
| 近すぎます | 2点の水平距離が1.5ブロック未満です。 |
| 遠すぎます | 2点の距離が、Createの最大敷設長（初期値32ブロック）を超えています。 |
| 急すぎて列車が通れません | 曲がる角度が135度を超える、半径が2ブロック未満、または既存の線路との角度差が約26度を超えています。 |
| 勾配が急すぎます | 曲線のどこかが上限より急です。最も急な所の勾配と上限がメッセージに出ます。上限は`curves.maxGrade`で、初期値は1000‰です。 |
| 曲線が折り返してしまいます | どちらかの端の向きが、2点を結ぶ方向と逆を向いています。 |
| 両端の向きが違いすぎて… | 1本の曲線ではつなげず、途中にアンカーを置く空きブロックもありません。 |
| アンカーを置く隙間がありません | アンカーを置くブロックが埋まっています。勾配モードでは、見ているブロックではなく、勾配で決まった高さのブロックが対象です。 |
| このアンカーは両側ともすでに曲線がつながっています | 前後の両方に曲線があるアンカーは、始点にも終点にもできません。 |
| 傾斜した線路のこちらの端には、すでに曲線がつながっています | 傾斜したCreateの線路のその端と、そこにつないだアンカーには、もう曲線があります。始点にも終点にもできません。 |
| 始点と終点が同じアンカーになります | 同じアンカーを2回選んでいます。 |
| 分岐からは開始できません | 複数の向きを持つCreateの線路は、端にできません。 |
| 傾斜した線路とは、その延長線上でまっすぐにしかつなげません | 傾斜したCreateの線路につなぐ曲線が、線路の延長線から外れているか、曲がっています。 |
| 傾斜した線路の上端からは上へ、下端からは下へしか延ばせません | 傾斜したCreateの線路の上端につなぐ曲線が上端より低い所を、下端につなぐ曲線が下端より高い所を通ります。 |
| 向きを反転するルートの一部が読み込まれていません | 反転するルート全体が読み込まれる位置まで近づきます。 |
| 始点の線路が失われています | 始点にしていた線路が壊されています。 |

### きれいな角度

曲線の自由な端の向きは、狙ったブロックの角度が15度の倍数に近いと、その倍数に引き寄せられる決まりです。刻みはサーバー設定`curves.snapAngle`で決め、0にすると無効にできます。近いとは、各角度の前後で刻みの4分の1以内のことで、15度なら3.75度です。これで、直角や45度の曲がりが、ブロック1つぶんずれずに正確に敷けます。

引き寄せ方は2通りです。狙ったブロックから2ブロック以内に、その角度がちょうどになるブロックがあれば、曲線はそこで終わります。45度の倍数はすべてこちらなので、直角に1ブロック足りない曲がりも、1本のきれいな円弧になります。もう1つは、終点を狙ったブロックのままにして、向きだけをその角度に回す方法です。30度や60度などはこちらで、円弧2本の間にアンカーが必要になることがあります。

手で回した端も同じで、角度の近くに来た目盛りでは、その角度に止まります。ただし、手で回している間、狙ったブロックは動きません。まだどのルートにも入っていないアンカーから出る線は、両端が格子に引き寄せられます。画面に距離を入力して敷く線と測量標は、与えた向きのままです。Createの線路と、すでに曲線があるアンカーも、向きは変わりません。ゴーストとメッセージには、敷かれる角度が出ます。格子のせいで曲線が敷けなくなるときは、狙ったブロックが与える曲線です。

### 勾配をつけて敷く

曲線の終点の高さは、ふつうは見ているブロックの高さです。勾配モードは、高さのかわりに勾配を決める方法で、高さは杖が計算します。

1. いつもどおり曲線を始めたら、ダッシュキーを押しながらスクロールします（1目盛り5‰）。勾配は上りも下りも上限`curves.maxGrade`までで、マイナスは下りです。0から動かすと、勾配モードに入ります。
2. 曲線を着地させたい地面の場所を見ます。そのブロックの高さは関係ありません。杖は、勾配で決まった高さに終点を置き、アンカーが入るブロックを枠で示します。そのブロックが埋まっている場合、ゴーストは赤です。
3. 右クリックで敷設します。選択は勾配を保つので、続けて右クリックすると、次の曲線も同じ勾配で敷かれる仕組みです。

メッセージの1行には、決めた勾配と、その曲線が実際に到達する勾配が並びます。表示の例は、「勾配モード ・ 設定 +35‰ → 実際 +40‰（終点）」です。

曲線は、始点ではルートがすでに持っている勾配で出ます。水平な地面とCreateの線路では水平です。そこから終点まで一定の割合で変わり、決めた勾配に着きます。そのため、水平な地面から出る曲線は、勾配へ滑らかに入っていきます。最初から最後までその勾配の曲線と比べると、上がる高さは約半分です。

水平に戻すには、勾配を0に戻します。次の曲線は水平に着き、そのあと勾配モードが終わります。始点がすでに水平なら、0に戻した時点で勾配モードが終わる決まりです。

勾配モード中は、空中のスニーク右クリックが下の画面に使われます。選択を解除するときは、スニークしながらブロックを右クリックしてください。

終点がCreateの線路や、すでにあるアンカーのときは、高さが決まっているので、勾配モードは使われず、いつもどおりの曲線になります。メッセージにもそう出ます。

#### 高さの丸め

ノードは、いつもブロックの高さに置かれるので、曲線が上がる高さは整数ブロックです。到達する勾配は、決めた勾配を、それで表せる値に丸めたものになります。短い曲線や緩い勾配ほど、丸めの影響は大きくなります。

水平な地面から出る曲線が上がる高さは、長さの半分に勾配を掛けた値を、最も近いブロックに丸めたものです。たとえば、Createの初期設定で最も長い32ブロックの曲線は、約31‰未満の勾配では水平のままです。35‰なら1ブロック上がり、63‰に到達します。

次の曲線は、前の曲線が到達した勾配から出て、また決めた勾配をめざします。同じ長さの曲線を続けると、勾配は、1本で2ブロック、4ブロック、6ブロックと上がる値に落ち着くので、32ブロックの曲線なら、62.5‰、125‰、187.5‰です。敷く前に、メッセージで実際の値を確かめてください。

曲線を長くするほど、決めた勾配に近づきます。最長はCreateの`trains.maxTrackPlacementLength`の設定で決まります。

100ブロックのリンクは、6〜7チャンクの長さです。線路グラフにリンクが加わるのは、両端のアンカーがロードされているときだけです。遠い側がロード範囲の外にあるリンクは、両端をロードできる距離まで近づくとつながります。両端がロードされていてもつながらないリンクは、`/createtrainnext rebuild`で戻せます。コマンドの節を参照してください。

#### 勾配と水平距離を入力する

入力欄は、勾配（‰）と水平距離（ブロック）の2つです。この画面は、勾配モード中にスニークしながら空中を右クリックすると開きます。水平距離を空にすると、勾配だけが設定されます。

水平距離を入れた場合、曲線は、選択中の端からその勾配で、その距離だけ敷かれる仕組みです。選択は新しい端へ進みます。狙うブロックがないので、曲線は始点からまっすぐ前へ出ます。

まっすぐ前とは、アンカーなら今のルートが進む向きで、Createの線路なら、そこから離れる向きのうち見ている側です。まだ曲線がないアンカーは、そのアンカーの向きとその逆のうち、見ている側へ出ます。

終点は、その線に最も近いブロックで、指定した距離との差は1.5ブロック以内です。距離はCreateの最大敷設長を超えられません。事前に表示は出ないので、敷設後のメッセージに、勾配、水平距離、高さが出ます。

### ルートをつなぐ、反転する、分ける

アンカーには、前後に1本ずつしか曲線をつなげられません。空いている側から曲線を出せるので、ルートの先頭から後ろ向きに伸ばすこともできます。

別々に引いた2本のルートは、端どうしを右クリックするとつながります。2本の向きが逆のときは、遠いほうのルートを、杖が端から端まで反転してからつなぐ仕組みです。反転しても線路は動かず、置いてある信号機の向きも変わりません。メッセージに「つなぐ先のルートの向きを反転します」と出るので、敷く前に分かります。

両端の向きが大きく違う曲線を1本のまま敷くと、逆向きに走る列車は、描かれたレールと別の形の経路をたどります。このため杖は、そのような曲線を2本の円弧に分け、間にアンカーを1つ置く作りです。置くブロックはゴーストの枠で示され、メッセージにも出ます。空いているブロックがなければ敷けません。

曲線の途中には、信号機や駅などを直接置けます。置きたいものを持って曲線に視線を向けると、視線の先の区間が枠で示されます。右クリックでその曲線を選び、もう一度、置きたい場所を右クリックする手順です。曲線を選べるのは、こうしたアイテムを手に持っているときだけなので、杖の操作は邪魔されません。信号機や駅が載っている曲線には、接続点を足せません。載っているものが曲線を失ってしまうためです。曲線の途中にレールのブロックがほしいときは、置きたい場所の近くを、スニークしながら右クリックして接続点を足します。接続点はアンカーなので、レールのブロックです。曲線の端に近すぎる場所や、すでに接続点がある場所には足せません。

Createの線路の端も、始点と終点にできます。使えるのは、平らな直線の線路と、45度の傾斜した線路です。杖が隣のブロックにアンカーを置き、Createの線路と同じ点で接続します。Createの線路につないだ端で選択は終わり、その先へは伸ばせません。分岐を含む線路は使えません。

傾斜した線路には、その延長線上でまっすぐにつなぎます。曲線は45度で線路から出入りし、水平に近づきながら進みます。上端からは登りながら、下端からは下りながら離れ、途中で折り返して戻ることはありません。傾斜した線路から始めると、終点は、狙ったブロックにいちばん近い延長線上のブロックになります。手で先端を回しても、向きは変わりません。

曲がりながらつなげないのは、45度の端と水平な端を結ぶ曲がった曲線が、行きと帰りで別の形になるためです。半径10ブロックの直角なら、約1ブロックずれます。Create自身の線路も、傾斜した線路からは曲がれません。

勾配モードで勾配を0にすると、曲線は水平になって終わります。`curves.maxGrade`を1000より小さくすると、45度の端が上限を超えるので、傾斜した線路にはつなげなくなります。

高さの違う2点も結べます。曲線は両端の間を一定の勾配で登り、両端のアンカーがその勾配を覚えているので、そこから伸ばしたルートは同じ勾配で続く仕組みです。片方の端がすでに決まっているときは、もう一方の端が、最もなだらかに曲がる勾配をとります。水平な線路から出て登る曲線が、登りへ滑らかに入るのはこのためです。曲線のどこでも超えてはならない勾配は、上限`curves.maxGrade`で決まります。初期値は、Createの傾斜した線路と同じ45度（水平1ブロックで1ブロック上がる勾配）です。

アンカーを壊すか、杖を持ってスニークしながら右クリックすると、そのアンカーの前後のつながりが外れます。ただし杖では、そのどちらかの曲線に信号機や駅が載っているあいだは外せません。

### 真っすぐな線を引く（測量標）

測量標は、方位、長さ、勾配を決めて、真っすぐな線路を引くブロックです。目で狙う杖とは違い、遠くの目標に向けて決まった角度で線路を出したいときに向いた道具です。

1. 線路を始めたい場所に測量標を置きます。
2. 方位、長さ、勾配を決めます。測量標を空の手で右クリックすると画面が開き、3つとも数字で入力できます。
3. 測量標を見ると、敷かれる線がゴーストで表示されます。杖で測量標を右クリックすると、その線が敷設されます。

方位は0から359度で、南が0度、時計回りに増えます。杖が表示する方位と同じなので、杖の表示を読んで測量標に入力できます。長さは3から128ブロックで、初期値は16です。ただし実際の上限は、Createの最大敷設長（初期値32ブロック）です。勾配は‰で表します。初期値は0で水平、マイナスは下りです。上限は`curves.maxGrade`で、上りも下りも同じ値です。

線は完全な直線になりますが、方位は少しずれます。アンカーのノードはブロックの中心に置かれ、線はその2点を結ぶためです。長い線ほどずれは小さく、16ブロックで平均0.5度未満、32ブロックで0.25度未満が目安です。敷設後のメッセージに、実際の方位と長さが出ます。測量標は敷設に使われ、その場所のアンカーになります。

勾配も同じように丸められ、線が上がる高さは整数ブロックです。たとえば16ブロックで100‰なら1.6ブロックですが、2ブロックになり、実際の勾配は125‰です。線の長さで1ブロックも上がらない緩い勾配では、線は水平のままになります。ゴーストと敷設後のメッセージに、実際の勾配が出ます。上限より急な線は敷けません。

### アンカー

アンカーは、曲線の端になるレールのブロックです。杖が必要な場所に自動で置くので、ふつうは手で置きません。手で置くのは、ブロックの位置を先に決めたいときです。置いたアンカーを杖で右クリックすると、そこから曲線を始められます。

アンカーはCreateのレールのブロックとして動くので、信号機などを置く対象にもなります。また、アンカーはその地点でルートが持つ勾配も覚えていて、そこから伸ばしたルートは同じ勾配で続く仕組みです。

### 信号機

日本式の信号機は、2灯式、3灯式、4灯式、5灯式、6灯式の5種類です。現示は、この信号機から先で連続して空いている閉そく（Createの信号が区切る区間）の数で決まります。先に信号機がない線路では、その信号機でいちばん緩い現示です。灯の番号は、上からの順です。

| 種類 | 灯（上から） |
|---|---|
| 2灯式 | 緑、赤 |
| 3灯式 | 緑、黄、赤 |
| 4灯式 | 黄、赤、黄、緑 |
| 5灯式 | 黄、黄、赤、黄、緑 |
| 6灯式 | 黄、緑、赤、緑、黄、緑 |

並びは、国の鉄道の基準にある図に合わせています。2灯式と3灯式は、赤がいちばん下です。以前のバージョンでは、2灯式は赤が上、3灯式は赤が真ん中でした。前に置いた信号機も、新しい並びで点きます。

点灯する灯の番号は、次のとおりです。「-」は、その信号機にない現示です。

| 現示 | 2灯式 | 3灯式 | 4灯式 | 5灯式 | 6灯式 |
|---|---|---|---|---|---|
| 停止 | 2 | 3 | 2 | 3 | 3 |
| 警戒 | - | - | - | 1と4 | - |
| 注意 | - | 2 | 3 | 4 | 5 |
| 減速 | - | - | 1と4 | 2と5 | 1と4 |
| 進行 | 1 | 1 | 4 | 5 | 4 |
| 高速進行 | - | - | - | - | 2と6 |

各現示になる、空いている閉そくの数は次のとおりです。

| 現示 | 2灯式 | 3灯式 | 4灯式 | 5灯式 | 6灯式 |
|---|---|---|---|---|---|
| 停止 | 0 | 0 | 0 | 0 | 0 |
| 警戒 | - | - | - | 1 | - |
| 注意 | - | 1 | 1 | 2 | 1 |
| 減速 | - | - | 2 | 3 | 2 |
| 進行 | 1以上 | 2以上 | 3以上 | 4以上 | 3 |
| 高速進行 | - | - | - | - | 4以上 |

警戒があるのは5灯式だけで、先の区間が短く、注意の速度からでは止まれない場所のための段階です。5灯式は、進行、減速、注意、警戒、停止の順に現示が変わります。以前のバージョンでは、警戒を使うかどうかをレンチで信号機ごとに切り替えられました。今は切り替えがなく、警戒をいつも使います。以前に置いた5灯式も、段階が1つ増えます。

置き方はCreateの信号機と同じです。信号機を持って線路を右クリックし、次に置きたい場所を右クリックします。置いた信号機はCreateの信号と同じ信号境界になり、列車は赤で止まります。Createの信号との併用も可能です。曲線の途中では、曲線そのものに視線を向けて置きます。「ルートをつなぐ、反転する、分ける」を参照してください。

信号機は、通過する列車の速度も抑えます。列車が通る瞬間の現示で決まり、初期値は警戒が25km/h、注意が45km/h、減速が75km/hです。サーバー設定の`signals.restrictedSpeed`、`signals.approachSpeed`、`signals.reducedSpeed`で変えられます。速度は次の信号機を通るまで続き、進行は何も制限しません。ただし6灯式は別で、緑1つの進行は初期値で130km/hに抑えます。この速度は`signals.sixAspectProceedSpeed`で変えられます。緑2つの高速進行は何も制限せず、この制限を解く扱いです。赤を通過した列車（運転席から操作する場合のみ起こります）は、警戒の速度に抑えられます。Create自身の信号機は、制限を解く点で高速進行と同じ扱いです。速度制限標識の制限とは別に働き、遅いほうが適用されます。標識と同様に、列車は先頭が信号機を通る瞬間にその速度になるよう、手前から減速します。減速の判断にはそのときに灯っている現示を使い、停止の信号機は、Createが列車を止めるので減速させません。

筐体は、中央、左、右のどれかに寄せられます。複線の間に柱を立てて、左右に頭を振り分けたい場面で便利です。寄せは値ボックスで選びます。向きは置いたときの自分の向きで決まり、22.5度刻みです。置いたあとに回す操作はありません。

6灯式は、1ブロックより高い18.25ピクセルあります。置かれるのは1ブロックだけなので、その上のブロックは空いていて、何でも置けます。上にはみ出す2.25ピクセルは、見た目だけです。視線を合わせることも、ぶつかることもできません。

列車を止めたり、閉そくを確保したりするのはCreateの処理で、この信号機は灯と、それで決まる速度を決めます。灯は約0.5秒ごとに更新されます。

### 中継信号機

中継信号機は、次の信号機の現示を手前で知らせる表示です。カーブの先や駅の屋根の陰のように、信号機が見えにくい場所で使います。列車を止めたり、閉そくを確保したりはせず、線路のグラフにも載りません。置き方は信号機と同じです。

灯はすべて同じ白で、7つのうち3つが点灯します。内容は並びの角度で読み取る作りです。

| 並び | 意味 | 次の信号機の現示 |
|---|---|---|
| 横に3灯 | 停止中継 | 停止 |
| 斜めに3灯 | 制限中継 | 警戒、注意、減速 |
| 縦に3灯 | 進行中継 | 進行、高速進行 |
| 消灯 | 表示なし | 次の信号機がない |

先で線路が分かれているときは、各方向の信号機のうち最も厳しい現示を示します。

### 速度制限標識

線路脇に立てて、制限速度の数字を表示する標識です。置き方は信号機と同じで、線路を右クリックしてから置きたい場所を右クリックします。標識に向けて右クリックを押し続けるとスライダーが開き、制限速度をkm/hで設定します。範囲は1から、Createの設定で列車が出せる最高速度までです。最高速度は、`trains`の設定にある`trainTopSpeed`と`poweredTrainTopSpeed`の大きいほうで、1ブロック毎秒を3.6km/hとして換算します。Createの初期設定では144になり、標識の初期値は40です。向きは置いたときの自分の向きで決まり、22.5度刻みです。

最高速度解除標識を置くと、制限速度を解除できます。置き方は同じで、数字のない専用の板が付きます。制限速度は最高値として扱うため、通過した列車は、その列車自身の最高速度でしか抑えられません。

標識が向いている方向に通過した列車は、その数字までに速度が抑えられ、次の標識を通るまで続きます。制限を解くのは、最高速度解除標識です。列車は標識の手前から、列車自身の減速の強さで速度を落とし、先頭が標識を通る瞬間に、その制限速度になります。反対向きに走る列車には効きません。最低の制限は1km/hで、列車が止まったまま動けなくなるのを避けるためです。列車ごとの制限はワールドに保存されます。

### 信号柱

信号機を支える、細い柱です。1種類のブロックで、柱にも、柱どうしをつなぐ横材にも使えます。伸びる向きは置いた面で決まり、隣の柱や信号機には自動でつながります。つながるのは、2灯式から6灯式までの信号機と、中継信号機です。速度制限標識にはつながりません。

信号機には、背面、下、上、左右の側面からつながります。前面にはつながりません。信号機の真上に柱や別の信号機があるときは、その信号機の柱がブロックの上端まで伸びてつながる作りです。レンチで右クリックすると、柱の向きを切り替えられます。長く伸ばすときは、柱を持って置いてある柱を右クリックすると、延長先の位置を補助してくれます。

### 曲線の床

Createの曲線には当たり判定がありません。乗ると落ちます。このModの曲線には、レールと同じ高さに見えない床を並べるので、上を歩けます。床は小さなブロックで、アンカーが数秒おきに更新する仕組みです。見ることも壊すこともできず、その上に建築すると消えます。床はレールに沿って4分の1ブロック刻みで高さが変わるので、45度の曲線でも歩いて上り下りできます。幅は線路と同じです。なお、Createの傾斜した線路そのものには当たり判定がないため、傾斜の上は歩けません。

止めたいときは、サーバー設定`curves.collision`をfalseにしてください。止めると新しい床は置かれず、すでにある床は数分で消えます。

## コマンド

すべて`/createtrainnext`で始まり、権限レベル2（op）が必要です。

| コマンド | 説明 |
|---|---|
| `junction <pos> [radius]` | 座標付近のレールのブロックが報告する軸、グラフのノードの有無、列車が通れる角度の判定を一覧にします。半径は0から8で、初期値は2です。列車が止まる、信号が置けないときの調査に使います。 |
| `probe <pos>` | 1つのレールのブロックについて、Createがステーションや信号の位置を決めるときに見る値と、その比較結果を表示します。アンカーだけでなく、Createの線路にも使えます。 |
| `curves [radius]` | 逆向きに読むと形が変わるカーブを一覧にします。今の杖は敷きませんが、古い版で敷いた曲線にあります。半径は1から1024で、初期値は128です。 |
| `repair [radius]` | 上のカーブを2本の円弧に直します。1回に最大16本です。レールは少し動き、東向きから北向きへ約20ブロックの曲線では半ブロック弱です。動いた距離は出力に表示されます。直したカーブの近くにいる列車は脱線します。 |
| `prune [radius]` | どのブロックも報告しなくなったグラフのノードを取り除きます。F3のグラフに残る色付きの柱です。ほかの線路、列車、信号は変えません。 |
| `rebuild [radius]` | 線路グラフから抜けているリンクを戻します。アンカーも曲線もあるのに、列車が走れないリンクです。働いているリンクは変えません。1回に最大32本です。遠い側がロードされていないリンクは判定できないので、その本数が出力に出ます。半径は1から1024で、初期値は128です。 |
| `reverse <pos>` | アンカーが属するルートを端から端まで反転します。2回実行すると元に戻ります。 |
| `resetgraph` | **ワールド内のすべての列車と線路グラフを消します。** 自動では戻りません。 |

`resetgraph`は、開発中の切り分け専用です。実行後は、各線路網のブロックを1つ壊して置き直し、アンカーをつなぎ直さないと、線路に辺が戻りません。実行前にワールドのバックアップを取ってください。

Createのクライアント設定`showTrackGraphOnF3`を有効にしてF3のデバッグ表示を開くと、線路のグラフのノードと辺が描かれます。

## 設定

設定は、設定ファイルを直接編集します。クライアント設定は`config/createtrainnext-client.toml`、サーバー設定は`config/createtrainnext-server.toml`です。ワールドの`serverconfig/`フォルダに同じ名前のファイルを置くと、そのワールドだけ値を上書きできます。

サーバー設定は、ワールドの中身に関わるため、接続するプレイヤー全員に同じ値が適用されます。

設定ファイルは、作られたときの値をそのまま使います。このModの以前のバージョンで作られたファイルでは`curves.maxGrade`が333のままなので、傾斜したCreateの線路につなぐには1000に書き換えてください。

| キー | 初期値 | 範囲 | 説明 |
|---|---|---|---|
| `curves.collision` | true | true、false | 曲線の床を置くかどうか |
| `curves.maxGrade` | 1000 | 10から1000 | 曲線や直線のどこでも超えてはならない勾配の上限（‰）。1000は45度で、Createの傾斜した線路と同じ勾配です。333にすると、水平3ブロックで1ブロックまでになります。1000より小さいと、傾斜した線路にはつなげません。 |
| `curves.snapAngle` | 15 | 0から45 | 曲線の自由な端が引き寄せられる角度の刻み（度）。0で無効です。45と90が格子に入るよう、45を割り切れる値にしてください。 |
| `signals.restrictedSpeed` | 25 | 1から1000 | 警戒の信号機が列車に課す速度（km/h） |
| `signals.approachSpeed` | 45 | 1から1000 | 注意の信号機が列車に課す速度（km/h） |
| `signals.reducedSpeed` | 75 | 1から1000 | 減速の信号機が列車に課す速度（km/h） |
| `signals.sixAspectProceedSpeed` | 130 | 1から1000 | 6灯式の信号機が、進行で列車に課す速度（km/h）。高速進行は何も課しません。 |

クライアント設定は描画だけを変えるため、プレイヤーごとの好みで決めてかまいません。

| キー | 初期値 | 範囲 | 説明 |
|---|---|---|---|
| `speed_limit_sign.fontScale` | 1.7 | 0.25から4.0 | 標識の数字の大きさ（倍率）。1.15以下だと3桁が白い部分に収まり、2.0を超えると3桁が標識からはみ出します。 |
| `speed_limit_sign.viewDistance` | 0 | 0から1024 | 標識を描く距離（ブロック）。0は描画距離いっぱいまで描きます。 |
| `multi_aspect_signal.litLampScale` | 1.0 | 1.0から2.0 | 点灯した灯を大きく描く倍率。1より大きいと、灯が枠の手前に出ます。1.35を超えると隣の灯にかかります。 |
| `multi_aspect_signal.glow` | true | true、false | 点灯した灯の周りに、同じ色の光の輪を描くかどうか |
| `multi_aspect_signal.glowSize` | 5.0 | 1.0から16.0 | 光の輪の幅（ピクセル） |
| `multi_aspect_signal.glowBrightness` | 0.5 | 0.0から1.0 | 光の輪の強さ。高いと、灯の近くで筐体が白く飛びます。 |
| `multi_aspect_signal.viewDistance` | 0 | 0から1024 | 灯を描く距離（ブロック）。0は描画距離いっぱいまで描きます。 |

## 仕組み

Createは、線路のグラフのノードを、X座標とZ座標を0.5ブロックの格子に丸めて扱います。ノードをこの格子に正確に乗せる必要があり、乗せられる向きは45度刻みの4方向だけです。Create自身の線路が45度と90度の刻みになるのは、このためです。

このModのアンカーは、ノードを4方向のどれかに置いたまま、曲線の向きは自由な値として別に持ちます。ノードの位置は格子に乗り、曲線の接線は好きな角度になります。曲線はCreateのベジェ曲線で、列車の走行、信号、閉そくの管理はCreateの仕組みがそのまま行う作りです。

勾配も同じ仕組みで持たせています。Createはベジェ曲線のハンドルを、与えられた向きの水平成分から計算するので、アンカーは曲線の向きを、水平な向きと登りの組として書きます。両端の登りが同じ曲線は、真上から見た形がそのまま保たれ、変わるのは登り方だけです。両端の登りが違う曲線は、形が少し崩れます。弦がCreateの最大敷設長の32ブロックになる直角の曲線を、水平から登りへ移すと、ずれは333‰で約0.2ブロック、1000‰で約1.4ブロックです。また、Createはノードを整数のブロックの高さに置くので、曲線が上がる高さは整数ブロックです。

傾斜したCreateの線路につないだアンカーは、ノードを1つだけ持ち、線路の端のノードを共有します。登る端のふつうの置き方でブロックの中心にノードを置くと、線路の端から半ブロック離れます。平らな端のように水平な区間を置くと、つなぎ目が45度で折れ、列車が通れません。

ベジェ曲線は、逆向きに走る列車用に、反対側の端から作り直されます。両端の角度が対称な円弧なら同じ形です。そうでない曲線では、2つの形が数ブロックずれることがあります。杖は、そのような曲線を2本の円弧に分けて、ずれを0.1ブロック以内に収めます。

ゴーストと、サーバーが敷く結果は、同じ計算（`CurvePlanner`）から出る仕組みです。見えている形と敷かれる形が食い違わないようにするためです。

## 制限と既知の問題

次の制限があります。

| 項目 | 内容 |
|---|---|
| レシピ | ありません。クリエイティブタブか`/give`で入手します。 |
| 端にできないCreateの線路 | 分岐を含む線路は、杖の始点にも終点にもできません。 |
| 傾斜した線路への接続 | 線路の延長線上でまっすぐにしかつなげず、`curves.maxGrade`が1000のときだけ使えます。 |
| 高さ | 曲線が上がる高さは整数ブロックなので、実際の勾配は設定とずれます。短い曲線や緩い勾配ほど大きくずれます。曲線の長さ1つぶんで1ブロックも上がらない勾配（32ブロックなら約31‰未満）は、水平のままです。 |
| 速度制限 | 列車が手前から減速できるのは、案内している経路か操舵の向きにある、前方の標識や信号機です。すでに速すぎる列車は、近くに現れた制限に、速いまま着きます。列車が近づく間に信号機の灯が変わると、そのときの現示で減速します。 |
| 分岐 | 1つのアンカーには前後に1本ずつしか曲線をつなげないので、アンカーだけでは分岐を作れません。 |
| 古いワールド | アンカーを壊した跡の色付きの柱や、逆向きに読むと形が変わる曲線が残っていることがあります。`prune`、`curves`、`repair`で直せます。 |
| マルチプレイ | 検証は十分ではありません。 |

```
./gradlew compileJava        # コンパイルだけ行います
./gradlew runClient          # クライアントを起動します
./gradlew runServer          # 専用サーバーを起動します
./gradlew runGameTestServer  # ゲームテストを実行します
```

IDEでライブラリが見つからないと表示されたら、`./gradlew --refresh-dependencies`でローカルのキャッシュを更新します。`./gradlew clean`はビルドの出力を初期状態に戻します。どちらもコードには触れません。

ゲームテストは`src/main/java/com/eyunya/createtrainnext/gametest/`にあります。曲線の計画、角度、勾配、長いリンク、測量標、杖のクリック処理、ルートの反転と結合、グラフの掃除と修復、曲線の上に置いた信号機の行き先が、本物のサーバーでの確認対象です。テスト用のワールドは`build/gametest/world`に作られ、実行のたびに消えます。GitHub Actionsは、pushとプルリクエストのたびに、ビルドとゲームテストを実行します。描画や、列車が実際に走る様子は自動では確かめられません。クライアントで確認してください。

Createは6.0.10のリリースに対してビルドします。Mavenの`6.0.10-281`は、ビルド情報（`META-INF/MANIFEST.MF`と`CreateBuildInfo.class`）を除いて、配布されている`create-1.21.1-6.0.10.jar`と同じです。`6.0.11-N`はCreateの開発中のビルドなので使いません。2026年10月時点で、最新のリリースは6.0.10です。6.0.10のPOMは、Registrate、Ponder、Flywheelを実行時の依存としてしか宣言していません。そこで`build.gradle`ではCreate本体だけを取得し、3つの版は`gradle.properties`で固定しています。

主なパッケージは次のとおりです。

| パッケージ | 役割 |
|---|---|
| `track/` | 曲線の計画（`CurvePlanner`）、アンカー、杖、測量標、曲線の床、グラフの掃除と修復 |
| `signal/` | 2灯式から6灯式の信号機（`SignalType`）と中継信号機 |
| `speed/` | 速度制限標識と、そのエッジポイント |
| `pole/` | 信号柱 |
| `client/` | 描画、ゴースト、画面 |
| `gametest/` | ゲームテスト |

レジストリ、設定、ネットワーク、コマンドは、パッケージの直下にあります。

ゲームが使わない2つのモデル、`relay_traffic_signal.json`（中継信号機のモデルのBlockbenchの元ファイル）と`housing_left.json`は、リソースの外の`src/main/blockbench/`に置いています。Minecraft 1.21.1が読めない自由回転を含み、`assets/createtrainnext/models/`の下にあると、読めないJSONごとにログへエラーが出るためです。自由回転を使う元ファイルは、今後もここに置きます。
